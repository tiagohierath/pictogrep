# Pictogrep keyboard and selection plan

Not built yet. Notes for the keyboard layer.

## Keys

| Key | Action |
| --- | --- |
| `/` or `Ctrl+F` | Focus search |
| `Esc` | Go back, close the modal, clear the current transient state |
| `Enter` | Open the selected picture |
| `Space` | Quick preview / larger preview |
| `←` `↑` `↓` `→` | Move between pictures |
| `J` / `K` | Next / previous picture, as optional aliases |
| `Home` / `End` | First / last |
| `Ctrl+A` | Select all |
| `Ctrl+C` | Copy the picture or its path, depending on context |
| `Ctrl+O` | Open or add a folder |
| `Ctrl+,` | Settings |
| `Delete` | Remove from the library, only if that is reversible or clearly explained first |
| `F` | Favourite |
| `T` | Folders (tags) |
| `R` | Similar pictures |
| `I` | Picture info and metadata |
| `G` | Grid / library |
| `?` | Shortcut cheat sheet |

## Selection

Steal from every file manager ever:

- Click selects.
- Shift+click selects a range.
- Ctrl+click toggles one item.

## The Pictogrep-specific one

Typing anywhere starts a search, unless focus is already inside a text field.
